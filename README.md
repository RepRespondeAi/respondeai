# Responde aí

## Objetivo

Criar uma plataforma onde alunos possam publicar dúvidas, exercícios ou procurar mentorias, enquanto outros usuários e mentores podem responder perguntas e oferecer serviços de mentoria.  

O projeto é inspirado em plataformas colaborativas como o Brainly, funcionando como uma rede social voltada para estudos e compartilhamento de conhecimento.
